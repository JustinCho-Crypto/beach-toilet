## 3. 코어 루프

```
지도에서 해수욕장/계곡 선택
  → 주변 화장실·샤워실 핀 + 청결도 배지 확인
  → 현장 방문, 3탭 제보 (GPS 반경 인증)
  → "감사 포인트 받기" → 보상형 전면 광고 시청 → 광고 완료 콜백에서 토스포인트 지급
  → 제보가 쌓여 데이터 품질 상승 → 다음 유저 유입
```

### 광고-포인트 순서 (중요)
- ~~포인트 지급과 동시에 전면 광고~~ ❌ → **광고 시청 완료 콜백 시점에 포인트 지급** ✅
- 이유: 보상형 광고 SDK의 보상 지급은 광고 시청 완료(reward callback) 기준. 포인트를 먼저 주면 유저가 광고를 즉시 닫아 광고 수익(=포인트 재원)이 발생하지 않고, 광고 정책 위반 소지도 있음.
- UX 문구: 제보 완료 → "감사해요! 광고 보고 OO포인트 받기" 버튼 → 전면 광고 → 지급 완료 토스트.

### 3탭 제보 항목 (확정)
1. **별점**: ★1~5
2. **청결도**: 깨끗해요 / 보통 / 더러워요
3. **요금**: 무료 / 유료
4. **(샤워실만) 온수**: 나와요 / 안 나와요 — 샤워실 제보에서만 노출되는 토글 1개
- 사진 제보 없음 (확정)
- 집계 표시: 최근 제보 가중 평균으로 핀에 청결도 배지(🟢🟡🔴) + 평균 별점 + "N일 전 제보"

### 포인트 지급 (확정 — 룰렛 제거, 2026-07-26)
- 제보 1건 = 보상 1회. "제보하고 토스 포인트 받기" → 전면 광고 완료 콜백 → **100~1,000원 토스포인트 즉시 지급** (룰렛 등 별도 연출 UI 없음)
- 기댓값은 100원에 최대한 근접:

| 금액 | 확률 | 기댓값 기여 |
|---|---|---|
| 100원 | 99.4% | 99.4원 |
| 500원 | 0.4% | 2.0원 |
| 1,000원 | 0.2% | 2.0원 |
| **합계** | 100% | **EV ≈ 103.4원** |

- ⚠️ **역마진 검증 필수**: EV 약 103원이 보상형 광고 회당 수익을 넘으면 제보당 손실. 금송아지 실측 eCPM으로 회당 수익을 확인하고, 미달 시 단가 하향 또는 지급 조건 조정 필요.

### 어뷰징 방어
- **GPS 인증**: 시설 반경 200m 이내에서만 제보 가능
- **쿨다운**: 같은 시설에 1인 1일 1회
- **보상 지급 1일 10회 제한** (일일 포인트 상한은 별도로 두지 않음 — 이론상 최악 1만원/일이지만 확률상 무시 가능, GPS 인증이 1차 방어)

## 4. 화면 구조

**탭 구조 (확정, 2026-07-26)**: 하단 중앙 **플로팅 알약형 세그먼트 탭 2개 — [지도 | 포인트]** (땡모반 지도와 동일한 패턴). 상단은 앱인토스 표준 미니앱 헤더(뒤로가기 · 로고 · 앱명 · ··· | X). 최하단은 **리스트형 배너 광고** 고정.

- **지도 탭**: 아래 1~3번 화면 전부 (지도 홈 → 스팟 상세 바텀시트 → 제보 플로우)
- **포인트 탭**: 모은 토스포인트 요약 카드 + 오늘 남은 보상(N/10) + 내 제보 이력 (기존 마이 화면을 탭으로 승격, TDS 스타일)


1. **홈 = 지도**
   - 카카오맵 JS SDK 전체 화면, 상단 검색/필터 칩(해수욕장·계곡·화장실·샤워실)
   - 스팟(해수욕장/계곡) 핀 + 시설(화장실/샤워실) 핀
   - 계곡은 생활안전지도 위험등급 표시 (위험지역 ⚠️ 배지 — 안전 가치 무료로 획득)
   - 하단 고정 배너 광고 (지도 컨트롤·현재위치 버튼과 겹치지 않게 지도 영역 위가 아닌 최하단 도킹, 오클릭 유도 금지)
2. **스팟 상세 (바텀시트)**
   - 해수욕장: 개장 여부·기간, 시설 목록(화장실/샤워실, 거리순), 청결도 배지
   - 계곡: 위험등급, 안전시설, 주변 화장실
3. **제보 플로우 (모달 3스텝)** — 위 3탭 + 포인트/광고 플로우
4. **마이**: 내 제보 이력, 받은 포인트, (v2: 랭킹/배지)

| 공중화장실 | [전국공중화장실표준데이터](https://www.data.go.kr/data/15012892/standard.do) 52,255건 (**2025.2부터 위경도 중단, 주소만**) | 스팟 반경 1.5km 필터 → 지오코딩 배치 (수천 건 규모) |

- 좌표 부정확(백사장 화장실 대표지번 문제)은 제보에 "위치가 달라요" 신고 버튼으로 보정 → 공공데이터 대비 차별화 포인트
- 파이프라인은 빌드타임 배치(정적 JSON) → 서버 비용 최소화. 제보만 서버(DB) 필요.
